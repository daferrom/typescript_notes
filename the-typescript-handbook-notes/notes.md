# The typescript handbook 

JS has grown for a simple script to the wide used languages used frontend and backend on the web

while size scope and complexity of programs written in JS has grown exponentially
The ability of the JS language to express the relationships between different units of code has not. 
Combined with Javascript's rather peculiar runtime semantics
this mismatch between language and program complexity has made JavaScript development a difficult task to manage at scale.

The most common errors can be described as type errors

The goal of TS is to be a static typechecker for JS programs.
A tool that runs before your code runs (static) and ensures that the types of the program are correct typechecked.
